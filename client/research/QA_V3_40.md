# Techno Team V3.40

## Changes
- syncSeeds / seedURLs / prep / discover: restore caller-supplied account identity and card independently of discovery results; preserve explicit exclusions; support bare website references in source text.
- platform / bookingDomain / candidateURL: classify medical directories separately from official-site candidates; retain profile-only Vezeeta constraints.
- discoverPlatforms / nameMatches / searchContext: retain relevant, cited profiles returned by a search for another platform; consider observed English identity aliases; compact retry on input rejection. No customer URLs or names hardcoded.
- search API: bounded legacy query/prompt compatibility and actionable input diagnostics with server version. Authentication, upstream model and cost controls unchanged.
- identity / flushIdentity: synchronous persisted decisions, deferred/coalesced extraction, usable identity controls during other analysis.
- languageVariant / linkedLanguageVariant / reconcileLanguageGroups: group confirmed language variants using a unique explicit cross-language profile link on the same host. Different people and country domains remain separate.
- identitySignalsHTML: show address-fragment / phone matches with source links as review signals, not automatic identity proofs.
- acceptExtract / unsupportedFinding / repair340: prevent directory service-absence diagnoses from partial/price-scope text; preserve old excluded findings in archive; separate platform contacts and patient review dates from doctor contacts/activity. No medical-quality inference from reviews.
- platformDeck / factKey: correct strength/issue summaries, language-account presentation, normalized duplicate facts, explicit review-date label.
- Backup name/version updated; existing storage keys and backup import format retained.

## Limits
The user's initial INVALID_INPUT was not reproduced live; compatibility, diagnostics and compact fallback were independently tested. Public readers/search may still fail or miss profiles. Directory pages without readable content remain unavailable, never counted as an audit. Explicit confirmation is still required for ambiguous people with the same name. Test customer snapshots and credentials are not included in this commit.
